01 Se repérer dans l’application

À l’ouverture, choisissez votre profil ou créez-en un. Lors de sa première utilisation, indiquez vos genres préférés pour personnaliser les suggestions.

02 Souris, tactile et télécommande

Sur Windows

Utilisez le menu latéral pour changer d’espace. Cliquez sur une affiche pour ouvrir sa fiche.

Faites défiler les listes avec la molette. Ctrl + F ou Ctrl + K donne accès à la recherche globale.

Sur téléphone

Utilisez la barre inférieure : Accueil, TV, Films, Séries et Plus. Le menu Plus regroupe les autres espaces.

Touchez une affiche pour l’ouvrir et glissez pour défiler. Sur un grand écran ou un téléphone déplié, la disposition s’adapte à la place disponible.

Sur TV / Fire TV

Déplacez le contour jaune avec les flèches. Appuyez sur OK pour ouvrir ou confirmer, et sur Retour pour revenir.

Dans un champ de recherche, appuyez sur OK pour ouvrir le clavier. Après avoir fermé le clavier, les flèches permettent de naviguer à nouveau.

En changeant d’onglet : la recherche est effacée et le défilement repart en haut. Vous pouvez donc revenir dans un catalogue sans rester bloqué sur une ancienne recherche.

03 Trouver un film ou une série

  1. Ouvrez Films ou Séries.
  2. Parcourez Récemment ajoutés, choisissez une catégorie ou saisissez un titre dans la recherche.
  3. Ouvrez une affiche pour consulter sa fiche et les actions disponibles.
  4. Si plusieurs versions sont regroupées, choisissez la version souhaitée selon les indications de langue ou de qualité affichées.
  5. Pour une série, choisissez la saison puis l’épisode avant de lancer la lecture.

Dans Par plateforme, choisissez un logo pour afficher le catalogue correspondant. Cette présentation sert à classer votre bibliothèque : elle ne remplace pas les applications des plateformes.

Le bouton Mettre à jour par internet actualise les informations de classement lorsqu’elles sont disponibles.

04 Favoris, profils et reprise

♥ Garder un favori

Sur une fiche ou une chaîne, sélectionnez le cœur. Il devient jaune. Sélectionnez-le à nouveau pour retirer le favori.

Retrouvez vos choix dans Favoris.

Reprendre un épisode

Ouvrez Reprendre depuis l’accueil ou le menu. Choisissez un titre commencé, puis utilisez l’action de reprise proposée.

Pour une série, l’épisode à reprendre est mis en évidence et la liste défile jusqu’à lui si nécessaire.

À chacun son profil

Les favoris, les préférences, l’historique et la progression sont associés au profil sélectionné.

Utilisez le bouton de profil pour changer d’utilisateur. Modifiez vos genres préférés dans Paramètres → Profil et envies.

Pour retirer un titre de la reprise, utilisez l’action de retrait de sa fiche. Sur Windows, un clic droit sur un contenu en cours ouvre aussi le menu Supprimer de Continuer à regarder. Sur mobile, un appui prolongé sur la vignette donne accès à ce menu.

05 Regarder la TV en direct

Ouvrez TV en direct, choisissez une catégorie si besoin, puis sélectionnez une chaîne. Sur TV, le focus se place sur la première chaîne disponible à l’entrée dans cet espace.

Affichez les commandes du lecteur pour accéder au plein écran. Le programme en cours et le suivant apparaissent avec les commandes lorsque le guide dispose de ces informations.

Télécommande : pendant une chaîne
Touche / actionRésultat
↑ / ↓Dans le lecteur, changer de chaîne. Si le menu des chaînes est ouvert, parcourir les chaînes de la catégorie affichée.
← / →Lorsque les commandes sont affichées, naviguer entre les options du lecteur. Dans le menu des chaînes, changer de catégorie.
OK, commandes masquéesOuvrir le menu des chaînes sur la gauche, sans quitter le plein écran. Le programme en cours est indiqué sous chaque nom lorsqu’il est disponible.

RetourFermer d’abord le menu ou les commandes affichées. Utiliser de nouveau Retour pour sortir du plein écran, puis quitter la lecture selon l’état du lecteur.

Les commandes TV comprennent l’actualisation de la chaîne, lecture/pause, le format de l’image et le plein écran. Si l’image se fige, essayez le bouton d’actualisation.

Si le programme n’est pas connu, « Programme indisponible » est affiché. Cela n’indique pas nécessairement un problème de lecture.

06 Utiliser le lecteur vidéo

Sur mobile, un appui simple affiche ou masque les commandes. Sur Windows, déplacez la souris sur l’image pour les afficher. Les commandes se masquent automatiquement après une période d’inactivité.

CommandeUtilisation
Lecture / PauseUtilisez le bouton du lecteur. Sur Windows, la barre d’espace permet aussi de mettre en pause ou de reprendre lorsque le lecteur est actif.
Barre de progressionPour un film ou un épisode, déplacez le curseur vers le passage souhaité. Le direct n’offre pas les mêmes possibilités de déplacement.
Épisode précédent / suivantPassez à l’épisode voisin lorsque ces boutons sont disponibles. L’enchaînement automatique peut être réglé dans les paramètres de lecture.
Sous-titresIls sont désactivés au lancement d’une nouvelle vidéo. Ouvrez leur menu pour activer une piste disponible.
AudioChoisissez une autre piste dans le menu audio lorsqu’il est proposé et que plusieurs pistes sont disponibles.
VitesseModifiez la vitesse pour les films et épisodes. Le direct reste à vitesse normale.
Format de l’imageChoisissez le rapport ou le recadrage souhaité avec le bouton de format. Un recadrage peut couper les bords de l’image.
Plein écranUtilisez le bouton dédié. Sur Windows, F dans le lecteur et F11 permettent de basculer le plein écran ; Échap permet d’en sortir.

Gestes sur téléphone

  • Glissement vertical à gauche : régler la luminosité.
  • Glissement vertical à droite : régler le volume.
  • Double appui à gauche / à droite : reculer / avancer de 10 secondes dans un film ou un épisode.
  • Pincement à deux doigts : modifier le format de l’image.
  • Verrouillage tactile : éviter les commandes accidentelles ; utilisez le contrôle de déverrouillage pour retrouver les commandes.

Les gestes dépendent de vos réglages de lecture. L’avance et le retour rapides ne s’appliquent pas au direct sans fonction de différé. Sur Windows, la molette au-dessus du lecteur règle le volume.

07 Personnaliser l’affichage

Ouvrez Paramètres → Bibliothèque et affichage sur TV, ou Bibliothèque et apparence sur Windows et mobile.

  • Affiches par ligne : augmentez le nombre pour voir davantage de films ou de séries à l’écran ; réduisez-le pour agrandir les affiches.
  • Tri, langues et catégories : choisissez ce qui apparaît dans les listes de chaînes, films et séries. Vous pouvez recocher un élément masqué plus tard.
  • Genres préférés : modifiez-les dans Profil et envies pour renouveler les suggestions de l’accueil.
  • Lecture : réglez notamment l’enchaînement des épisodes, la vitesse et les gestes proposés par votre appareil.
Pour une lecture plus confortable sur TV : gardez peu d’affiches par ligne et suivez le contour jaune avant d’appuyer sur OK.

08 Réduire, fermer et mettre à jour

Depuis l’accueil Android ou TV, appuyez sur Retour pour afficher les choix de sortie. Sur Windows, utilisez le bouton de fermeture de la fenêtre.

Réduire

Quittez l’écran de l’application en conservant la session en mémoire, pour revenir plus rapidement.

Android ou Fire OS peut libérer l’application si la mémoire manque. Une réouverture complète sera alors nécessaire.

Fermer

Terminez la session de l’application. Le prochain lancement effectuera son démarrage habituel.

Annuler

Fermez la boîte de dialogue et continuez à utiliser NOVA.

Installer une mise à jour

  1. Ouvrez Paramètres → Mise à jour de l’application.
  2. Choisissez Vérifier les mises à jour.
  3. Si une version plus récente existe, suivez les indications. NOVA choisit le fichier correspondant à votre édition.

Sur Android et TV, confirmez l’installation dans l’écran système et accordez l’autorisation d’installation si elle est demandée. Sur Windows, le bouton ouvre le téléchargement du ZIP portable : fermez NOVA puis extrayez tout le dossier de la nouvelle version.
